# BIMS: preostali rad
1. Ovlaštena BIMS sesija i read-only provjera: list/detail/statusi/šifrarnici; rezultat je sanitizovan ugovor s dokazima.
2. Dogovor s FUZIP o podržanom integratoru, testnoj okolini i ovlastima; rezultat nije samo uspješan OIDC login.
3. Nakon ugovora implementirati adapter, korelaciju, idempotentnost i unknown outcome postupak; prihvat traži testne odgovore, bez slijepe ponovne predaje.
4. Potvrditi pravila primjenjivosti zdravstvene/fito/kvalitete po robi i nadležnosti prije automatizacije.
5. U zajedničkoj testnoj instanci provjeriti stvaran upload, zadržavanje i prikaz priloga; screenshot sintetičkog pregleda nije stvarni integracijski test.
